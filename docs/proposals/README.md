# Proposals — archival

Everything in this directory is an archival record: a proposal, a plan, an inventory or a
dogfood log as it stood on its date. None of it is doctrine, and none of it binds a run. Where a
record describes a human gate or a run-wide stop, it describes the factory before P-0001
(founder, 2026-10-18: the run involves the founder only at a genuine impasse; nothing stops the
run or waits on the founder). The current doctrine is `prompts/`, `docs/SOFTWARE-FACTORY.md`,
`docs/HARNESS.md` and `docs/standards/`. `scripts/check_no_human_gates.py` does not scan this
directory, because rewriting a dated record would falsify it.
