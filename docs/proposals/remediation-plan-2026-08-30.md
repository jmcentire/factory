## Phase 0 — Instrument and baseline (before any deletion)

### 0.1 Refusal-path event instrumentation
Every refusal exit — `dispatch_lane.sh` refusals, `phase1_gate.sh` (gate G), `promote.sh` fail-close, endgame NOB — writes one host-timestamped line to `events.jsonl` before exiting. Without this, the earliest deaths produce no derivable signal and the acceptance instrument fails the best-case early-NO run.
**Enforcement:** host shell code writes the line inside the existing serialized-writer discipline; a lane that skips endgame leaves `verdict.json` absent and the checker fails closed. Forcing test: each refusal path produces exactly one event with a kind in the committed closed set, enforced structurally — a per-script chokepoint scan makes a refusal exit without an event call unrepresentable — plus dynamic per-site tests where fixtures reach the site.
**Boundary (amended 2026-08-30, verification round 2):** dispatch refusals occurring before the run root exists — argparse/usage exits, the unknown-role exit, and `factory_load_context` failure — are exit-code-only; `events.jsonl` lives in the run root, which does not yet exist at those exits. No global pre-root sink is specified. BLOCKED verdict exits (promote exit 1, endgame RED/GREEN) are deliberately uninstrumented: a rendered verdict is already a recorded terminal signal.

### 0.2 Host-written terminal-NO record

**Enforcement:** the record is written by host code only; lanes have no write path to the control root (denial probe registered — see 0.5). **The deadline-expiry host-recorded-NO is a BOUND, not a signal: it is excluded from the committed NO-relevant kind-set and reported as a separate class**, so the deadline knob cannot manufacture the terminal event the instrument rewards (the deadline/instrument complecting the acceptance skeptic caught).
**Disposition, round-3 G1 (endgame set-e crash deaths):** endgame paths that die under `set -e` without reaching an instrumented refusal exit (workspace mkdir, git subshells, the verdict-write python) currently leave neither event nor verdict; the standing control is the verdict-absent backstop — the checker's pass rule fails closed on a harness with no terminal — and trap-based instrumentation of this class lands with 0.4c's watchdog (which bounds the same silent-death window by wall-clock), not before. - **No per-gate clean-run retirement counters, no N-run thresholds, no LLM-authored attestation path.** Clean runs are farmable by steering away from the trigger surface (the O-ring trap in our own doctrine).
- **No replacement judge-of-the-judge.** Behavioral qualification is deleted (2.3), not upgraded — the recursion floor is Gate I's declared terminality plus the structural import-scan.
- **No stored dependency-graph artifact.** Edges are recomputed per-call from digests the lane artifacts already carry.
- **No general unregistered-gate detector.** Closed-world orphan enforcement only; the core-symbol orphan direction is named as an unrealizable residual.
- **No silent recovery.** Projection mismatch re-derives AND emits a signal; every disposition, including Recovered, is recorded; every apology path has a forcing test and a degraded-disclosure record.
- **No optional-v1 execution requests after Track B's freeze, no permanent unkeyed "legacy" acceptance, no in-place schema semantics drift.** Greenfield stays on v1 until Track B freezes /2.
- **No gates_paid hard gate on n=1.** Its demotion is a stated decision-residual, not an enforced invariant.
- **No new gate without a registered row and denial probe** — the plan's own gates (tier selection, registry checks, write-path exclusivity, terminal-NO record, apology paths) register themselves.
- **No prose controls added anywhere.** The glossary checks are exact-token and digest-bound referent-integrity, not paraphrase policing (ruling 5a).
- **runner_isolation.py:684 was not "fixed"** — verified by design for the networked runner class.
- **Did not treat the single-operator anchor as a defect to design around twice** — assumed (per the synthesis constraint); the verified defect — the promised anchor verification seam does not exist — is fixed (4.1).
- **No 7b re-architecture in this plan.** The state-machine reframe ships as 7a (the 0.6 classification audit) plus targeted demotions/deletions; rebuilding the machine before shipping anything is the "doctrine applied to everything except itself" trap.
- **No repair authority inside the repaired file.** chain-repair and ledger-unlock are out-of-band, operator-keyed, signed, and consumed by the loader.
- **No claim that tiering fixes single-human serialization.** It does not; the serialization half of pattern 5 is consciously accepted under the single-operator constraint.
- **No claim the greenfield acceptance remediates the brownfield latency thesis.** It does not; Track B's own run does, and Track B has a forcing event.
