# REVIEW.md — automated review guidance for this repo

Method and rule IDs: [`docs/standards/REVIEW.md`](docs/standards/REVIEW.md). Cite findings by rule
(A# architecture, W# code, T# tests). Agent-reviewer rules: [`prompts/code-review.md`](prompts/code-review.md).

## Always check

- **Generic by construction.** Nothing in `factory_core/`, `factory_runtime/`, `prompts/` or `docs/`
  (outside `docs/HISTORICAL_MARKDOWN/` and `docs/PROVENANCE-SYNC.md`) names a consuming target, its
  services, its people or its internal numbers. `make check-purity` catches code; prose is on you.
- **`make ship` passes** — purity, doctrine, wiring, authority, harness, denial-probes, acceptance,
  glossary, lint, typecheck, tests. A PR that claims green without the run is a C10 finding.
- **Prompt edits regenerate the doctrine.** Any change to `prompts/validate.md`, `engineer.md`,
  `test.md` or `diff-intent-gate.md` must ship with `docs/ROLE-DOCTRINE.md` regenerated by
  `scripts/assemble_role_doctrine.py` (round-trip proven). A hand edit to `ROLE-DOCTRINE.md` is a Blocker.
- **No gate or monitor is weakened, deleted or silenced** by the change it judges. Every new gate in
  `harness/gates.tsv` carries a collecting denial probe with a named red_now.
- **Structural doctrine parity.** `docs/SOFTWARE-FACTORY.md` section numbering, the four roles, the
  three phases and the eight non-negotiables are parsed by `scripts/check_doctrine_sync.py`; renumbering
  is a doctrine change, not an edit.
- **Partial work is never marked done.** Status words ("verified", "proven", "done") cite a run or a
  `file:line`.

## Style

- Prefer stdlib; the only runtime third-party dependency is `jsonschema`.
- Code follows [`docs/standards/HOW-WE-WRITE-CODE.md`](docs/standards/HOW-WE-WRITE-CODE.md); tests
  follow [`docs/standards/TESTING.md`](docs/standards/TESTING.md).
- Reports to the human follow [`docs/standards/RESPONSE-STANDARD.md`](docs/standards/RESPONSE-STANDARD.md):
  status first, decisions and questions called out, every recommendation with its reason, no
  unexplained identifiers, what's next and what's blocking.

- `docs/HISTORICAL_MARKDOWN/`, `docs/PROVENANCE-SYNC.md` (historical record)
- `*_baseline.json`, `removal_ledger.jsonl`, `factory_core.egg-info/`, `build/`
